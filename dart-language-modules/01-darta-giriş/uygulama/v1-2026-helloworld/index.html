🎯 Dart Programlama Mimarisi

Bu proje, spor bilimi prensiplerini Dart dilinin temel taşları olan int, double, const, final ve if/else yapılarıyla modellemiştir.

1. int ve double Türleri Değişkenler

Tam sayı sayımları (set, tekrar, dinlenme süresi) için int; ağırlık ve tonaj gibi hassas ondalık değerler için double kullanılır. 

// Sayısal Veri Türleri:
int sets = 3;             // Tam sayı
int reps = 10;            // Tam sayı
double weight = 72.5;     // Ondalıklı sayı (kg)

// Otomatik double dönüşümü:
double volume = sets * reps * weight; // 2175.0 kg
2. const ve final Sabitleri Sabit Prensipler

const: Değiştirilemez spor prensipleri (derleme zamanı sabitleri).
final: Çalışma zamanında hesaplanan ve sonradan değiştirilemeyen antrenman hacmi. 

// const: Evrensel değişmez kurallar
class TrainingPrinciples {
  static const int defaultRestPPL = 90;
  static const int defaultRestLegs = 120;
  static const int failureBonus = 30; // +30 sn
  static const double overloadStep = 2.5; // +2.5 kg
}

// final: Çalışma anında hesaplanan tek seferlik değer
final double calculatedVolume = sets * reps * weight;
final DateTime workoutDate = DateTime.now();
3. if / else Karar Blokları Tükeniş & Hedef

Tükeniş (failure) ve hedef kontrolü ile sporcuya anlık toparlanma ve aşırı yüklenme (progressive overload) geri bildirimi verilir. 

// Tükenişe ulaşıldı mı kontrolü:
if (reachedFailure == true) {
  // Merkezi sinir sistemi toparlanması için +30 sn
  restSeconds += TrainingPrinciples.failureBonus;
}

// Hedef tutturuldu mu kontrolü:
if (reps >= targetReps && weight >= targetWeight) {
  status = "Hedef Tamamlandı! Gelecek seans ağırlığı artır.";
} else {
  status = "Hedef tutmadı. Aynı ağırlıkta kalın.";
}
